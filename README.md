# مغامرة سكامبر — SCAMPER Adventure

لعبة تعليمية تفاعلية باللغة العربية للأطفال من 7 إلى 12 سنة لتعلّم أول أداتين من SCAMPER:

- **S — Substitute — الاستبدال**
- **C — Combine — الدمج**

## تشغيل المشروع محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

## النشر على GitHub Pages

يمكنك تسمية الـRepository بأي اسم. إعداد Vite يكتشف اسم المستودع تلقائيًا عند البناء داخل GitHub Actions.

1. أنشئ Repository جديدًا على GitHub.
2. ارفع **محتويات** هذا المجلد إلى فرع `main`.
3. افتح: **Settings → Pages**.
4. تحت **Build and deployment** اختر **GitHub Actions**.
5. افتح تبويب **Actions** وانتظر Workflow باسم **Deploy SCAMPER Game to GitHub Pages** حتى يصبح أخضر.
6. ارجع إلى **Settings → Pages** وستجد رابط اللعبة المنشور.

سيكون الرابط غالبًا بالشكل:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## تعديل محتوى اللعبة

المحتوى التعليمي الرئيسي موجود في:

`src/App.jsx`

تحت التعليق:

`EDITABLE GAME CONTENT`

ومن هناك يمكن تعديل:

- الأسئلة
- الإجابات
- التغذية الراجعة
- أسماء الشخصيات
- المراحل
- أنشطة الاستبدال والدمج

## ملاحظات مهمة

- السحب والإفلات يعمل فعليًا على أجهزة الكمبيوتر.
- على الهواتف والأجهزة اللوحية يمكن استخدام النقر كبديل موثوق للسحب.
- التقدم يُحفظ محليًا في المتصفح باستخدام Local Storage.
- لا توجد قاعدة بيانات أو مفاتيح API أو تسجيل دخول.
- لوحة المعلم تتضمن الصوت، وضع العرض، مستوى الصعوبة، الانتقال بين المراحل، كشف الإجابات، وإعادة ضبط اللعبة.
